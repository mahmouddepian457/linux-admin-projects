This prohect aim to create a simple web server instalintion and we use nginx

Scenario:

	Install either Apache or Nginx.
	Be able to start, stop, and restart it.
	Make it auto-start on reboot using systemd.
	Check and follow service logs.
What you will practice:

	Using systemctl commands
	Understanding service files
	Using journalctl for logs
Commands Used:

	yum search nginx yum install nginx systemctl enable nginx systemctl start nginx ,systemctl stop nginx, systemctl restart nginx ,jornalctl -u ngin
